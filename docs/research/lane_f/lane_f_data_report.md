## 2. Quality-audit calibration (synthetic, known truth)

5 synthetic markets × 40 symbols × 750 sessions were generated with known corruption: unadjusted splits, 1 % missing bars and delistings after a decline. The audit was scored against the truth. Paired clean markets measure its false alarms.

| defect | result |
|---|---|
| unadjusted splits, RETROSPECTIVE audit (uses the following bars' volume) | recall 96.9 %, precision 98.4 % (62 found, 2 missed, 1 false alarms) |
| unadjusted splits, POINT-IN-TIME flags (bar i uses bars <= i only) | recall 87.5 %, precision 98.2 % (56 found, 8 missed, 1 false alarms) |
| missing bars (count per symbol exact) | 200 / 200 symbols |
| delistings flagged as ended early | 198 / 200 symbols correct |
| clean markets graded clean | 191 / 200 symbols |

**Knowledge timing.** The retrospective audit sees the whole sample. It may describe a dataset, but it must never select a historical universe, because that would be look-ahead. Point-in-time eligibility uses `causal_split_flags` or `audit_symbol_asof`, at the lower recall shown.

**Provider quality flags.** Warning bits (zero volume, outlier warned, duplicate kept) grade a symbol `usable_with_warnings`, reported per bit. Blocking bits (backfilled gap, and any unknown bit, which fails closed) also remove the row from `research_view`, the only bar view the other lanes consume.

Limits: synthetic splits are exact ratios (2, 3, 4) with clean volume inversion. Real feeds mix splits with news gaps, reverse splits and partial adjustments, so expect lower precision on real data. A detected split is a flag for review, never an automatic adjustment.
