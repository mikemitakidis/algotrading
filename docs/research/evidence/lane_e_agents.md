## 3. What is still required before any real agent runs

- An OS/container sandbox for any generated code: no secrets, no network, read-only inputs. `research.boundary` is a lint, not a sandbox.
- Operator approval for any model or API usage, any scheduled or paid agent, and any write beyond an isolated branch.
- A separately held authority for pre-registration attestations and holdout releases (lane B).
- Operator verification of every citation an agent records. `verify_source` requires the operator's signature over the source's content, checked by an operator verifier the library is built with; the mock library has none, so its citations stay unverified. The verifier is the lane B local HMAC model, not an independent authority.
